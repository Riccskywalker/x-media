# x-media

Public media for my X posts, hosted so Buffer can attach images from a stable raw URL.

Files are grouped by year and month:

```
2026-11/codex-vs-claude-code.jpg
```

Raw URL pattern:

```
https://raw.githubusercontent.com/Riccskywalker/x-media/main/<path>
```

Example:

https://raw.githubusercontent.com/Riccskywalker/x-media/main/2026-11/codex-vs-claude-code.jpg
